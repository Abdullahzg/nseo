generation," "Imagine MCP for video generation" — same page shape, different target product). No
testimonials and no interlinking block in this template — that's by design, not an omission; don't add
them unless asked. *(Word counts below were bumped +15 per section from the original spec on 2026-07-29 —
treat these as the current targets.)*

## Section 2 (setup steps) — reusable copy

This is real, reusable step-by-step copy for connecting to ImagineArt's MCP server — use it close to
verbatim on every MCP page, only swapping the final action to match whatever that specific server does
(e.g. "generate an image" vs. "generate a video"). The steps themselves are fixed short instructions, not
subject to the word-count bump above — don't pad them out:

- **01 Open Your Client** — Launch Claude. Open Settings → Connectors → Add custom connector.
- **02 Add The Server** — Name it Imagine MCP and paste this URL: `https://mcp.imagine.art` (Copy button
  next to the URL)
- **03 Connect & Create** — Click Add → Connect, sign in with imagine.art, then ask Claude to generate an
  image. *(swap "generate an image" for the relevant action on non-image MCP pages)*

## Notes for filling this in

- Every H2 except the two bulleted ones and the setup one is a short, single-idea section (35 words) —
  resist padding these out past that.
- The two 5-bullet sections want genuinely single-word bullets (not short phrases) — that's a deliberate,
  punchy format, not a word-count target to hit loosely. Only the intro sentence before the bullets grew
  with the word-count bump; the bullets themselves stay one word each.
- No testimonials section and no explicit interlinking block here, unlike Video T1 / Image T7 — don't add
  either unless the person asks for this page to include them.
