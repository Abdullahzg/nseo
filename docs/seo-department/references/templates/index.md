# Page template index

When someone says "I need content for [template name]" (e.g. "video T1," "image T7," or, once added,
something like "ad studio T1"), match it against this index and use the exact structure in the linked
file — don't improvise a structure of your own when a named template exists.

| Template name | File | Content type |
|---|---|---|
| Video T1 | `video-t1.md` | Feature/landing page for a video-generation tool or use case |
| Image T7 | `image-t7.md` | Feature/landing page for an image-generation tool or use case |
| MCP | `mcp.md` | MCP server/connector landing page (e.g. Imagine MCP for image/video generation) — includes reusable setup-step copy |
| Ad Studio | `ad-studio.md` | Ad Studio (or similarly product-flow-driven) feature/landing page |

**If the person references a template name that isn't in this table yet** (e.g. a studio-specific one
they haven't handed over): don't guess at a structure or reuse a different template's shape and hope it's
close enough. Ask them for it, save it here the same way the ones below were saved, and add a row to this
table. Once you have it, it's reusable forever — that's the entire point of saving these.

Templates differ from each other in which blocks they include (some have a CTA block or an interlinking
block or testimonials, some deliberately don't) — always follow the specific template's own spec rather
than assuming every page needs the same set of blocks.

## How these get used

1. Match the requested template name to a file here.
2. Pull the keyword research for the page (primary + secondary keywords, FAQs) from the relevant Notion
   research — see the main SKILL.md and `../notion-database.md`. Don't invent keywords when research
   already exists for the page; if it doesn't exist yet, do that research first (Workflow A/B) before
   drafting.
3. Follow the template's structure exactly: same heading levels, same word counts (treat these as targets
   to land close to, not hard limits to the word — a section spec'd at "60 words" should read as a tight
   60-ish word paragraph, not 30 or 150), same section order, same formatting quirks (e.g. Image T7's
   bullet-format sections).
4. Slot the primary keyword into the H1 and naturally into the first H2; secondary keywords into
   supporting H2s where they fit naturally — don't force a keyword into a sentence where it reads awkwardly.
5. Content drafting itself (not just following the structural template) also needs brand/writer voice —
   see the "Planned: Workflow C" section of the main SKILL.md for whether that's been supplied yet.
