# Brand voice — options and lookup

Three tone-of-voice guides are saved here. Before drafting any content (Workflow C), present these three as
an explicit choice to the person and wait for them to pick — never default to one, never guess, never blend
two without being told to.

| Option | File | When it fits |
|---|---|---|
| **Misher Writer** | `misher-writer-tone.md` | A strong, personal, industry-veteran voice — first-person war stories, opinionated, structured around "the 11pm call." Built for the F&B creative cluster and any piece where a named personal voice should carry the read over the house brand voice. |
| **ImagineArt Blog Tone of Voice** | `blog-tone-of-voice.md` | The default for ImagineArt's own blog posts and long-form guides. Confident, sharp, results-driven third-person brand voice — the strategist who's shipped the work, not just written about it. |
| **ImagineArt Landing Page Tone of Voice** | `landing-page-tone-of-voice.md` | Hero lines, feature copy, CTAs, microcopy on imagine.art pages. Built around four selectable tones per section (authoritative, confident, approachable, witty-sparingly) rather than one fixed voice. |

## How to present the choice

Ask something like: *"Which voice should this be written in — Misher Writer, ImagineArt Blog Tone of
Voice, or ImagineArt Landing Page Tone of Voice?"* If the content type makes one obviously the house
default (a blog post → Blog Tone of Voice; a feature/landing page → Landing Page Tone of Voice), it's fine
to name that as the suggested default while still letting the person override it — but always surface the
other two as options rather than silently applying the default.

## Rules that apply no matter which voice is picked

All three guides independently converge on the same hard constraints — enforce these regardless of which
option is chosen:

- No em dashes. Restructure into two sentences instead.
- No random mid-sentence bolding for emphasis (bold headings and true key terms only — Image T7's
  bullet-label format is the one deliberate exception, since bolding there is a structural label, not
  emphasis).
- Sentence case in headings, not Title Case.
- No banned/generic AI phrases ("unlock," "elevate," "game-changer," "seamless," "in today's fast-paced
  world," "whether you're a... or a...," "in conclusion," etc. — see each guide's full list).
- Every claim backed by a number, name, or mechanism — not an adjective.
- At most one joke per section if using a wittier register, and it should land without being explained.
- Read the opening line out loud — if it could open any AI company's page, rewrite it.

## Note on the 20 already-published Notion drafts

The 20 "content" pages written into the Page List + KW Research database before these tone guides existed
used em dashes and bold-label bullet stacks throughout, which conflicts with the rules above. Those pages
haven't been re-passed for voice — flag this to the person if it comes up, rather than silently rewriting
pages nobody asked to have redone.
